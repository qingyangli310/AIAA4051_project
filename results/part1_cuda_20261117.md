# Part 1 CUDA results (2026-11-17)

Formal run: seed 42, three epochs, greedy decoding, one NVIDIA RTX A6000.
Code base: commit `93d260d` on `feature/part1-complete`.

## Data budget

| Task | Train | Dev |
|---|---:|---:|
| Generation | 1,000 | 20 |
| Verification | 1,500 | 90 |
| Repair | 1,500 | 90 |
| Total | 4,000 | 200 |

Repair therefore used 1,500 unique training examples. Three epochs produced 4,500
sample presentations, not 4,500 distinct examples.

## Dev-only model selection

| Model | Generation success | Feasibility | Unique predictions |
|---|---:|---:|---:|
| T5-small | 0/20 | 0/20 | 3 |
| BART-base | 1/20 | 12/20 | 4 |

BART-base was selected using Dev only. Test results were not used for selection.
The selected model is still a weak Generation baseline: most predictions belong
to a few repeated paths.

with the wrong targets, and the correctly paired loss was lower for 84/90 examples.
