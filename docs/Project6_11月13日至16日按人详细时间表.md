# Project 6 11月13日至16日按人详细时间表

> 时间范围：2026 年 11 月 13 日至 11 月 16 日  
> 环境划分：Train 70% / Dev 10% / Held-out Test 20%，三者按 `environment_id` 划分且两两无交集。  
> 测试规则：同一批 Held-out Test 环境同时用于 ID 单错误条件和 OOD 双错误条件，并通过 `base_sample_id` 一一配对。  
> 分工：A 负责 PPNL 数据与 executor；B 负责 Generation 与 Verification；C 负责 Repair、指标和端到端集成。
